# Название проекта: WeatherSniffer CLI

**WeatherSniffer** - это легковесная утилита командной строки для быстрой проверки погоды прямо из вашего терминала. Написана на Python и работает быстрее, чем открывается браузер.

## Основные возможности
* Получение текущей погоды по названию города
* Автоматическое определение геолокации по __IP__
* Поддержка вывода данных в формате __JSON__ для интеграции со скриптами

## Быстрый старт
Чтобы установить утилиту, выполните команду в терминале: `pip install weather-sniffer`

## Порядок использования
1. Для базового запуска введите команду `weather-sniffer`
2. Чтобы узнать погоду в конкретном городе, используйте флаг `--city`, например: `weather-sniffer --city Riga`
3. Для получения ответа в формате __JSON__ добавьте флаг `--json`

## Пример JSON-ответа от API
```json
{
    "status": "success",
    "data": {
        "city": "Riga",
        "temperature": "+18C",
        "condition": "Partly Cloudy"
    }
}
```
